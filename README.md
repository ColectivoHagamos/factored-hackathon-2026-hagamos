# VERA · dispute assistant for LATAM Bank

**VERA** (from *verification*) handles the first contact of a transaction dispute at **LATAM Bank**, the synthetic bank of the Factored AI & Data Hackathon 2026 (Mexico, Colombia and Argentina; Spanish and Portuguese). It **V**erifies before acting, **E**xplains with the rule and its source, **R**ecords and reads back the case, and **A**ccompanies the customer with a human always available.

> **Status:** under construction. This version contains the repository structure and the architecture rule; the remaining components arrive in stages.
> **Demo:** https://vera.colectivohagamos.com (published with the first deployment).

## Repository layout

Hexagonal architecture (ports and adapters): the domain does not depend on infrastructure.

| Folder | Contents |
|---|---|
| `vera/contracts` | Boundary models (Pydantic) |
| `vera/ports` | Domain interfaces: identity, transactions, cards, cases, routing, audit and interpreter |
| `vera/core` | Dispute flow as a state machine |
| `vera/policy` | Policy rules (POL-*, PROH-*) and per-country legal clock |
| `vera/tools` | Tools behind a single action gate (confirmation, idempotency and read-back) |
| `vera/adapters` · `vera/llm` · `vera/gateway` | Data, language model and customer text entry point |
| `vera/output` | ES/PT templates, reply validator and handoff |
| `api/` · `web/` | HTTP API `/v1` and the customer and analyst pages |
| `pipeline/` · `ml/` · `evaluation/` | Data preparation, learned component and evaluation |
| `docker/` · `deploy/` | Images and deployment |
| `docs/adr/` | Architecture decision records |
| `docs/schemas/` | JSON Schema of every boundary model, generated with `python -m scripts.export_schemas` |
| `tests/` | Unit, contract, property, architecture and end-to-end tests |

## Tests

```bash
uv sync
uv run pytest
uv run ruff check .
```

Continuous integration (GitHub Actions) runs on every pull request and on every push to `development`, `qa` and `production`: lint, format, tests and `scripts/check_publication.py`, which blocks the publication of data, secrets, forbidden files and files larger than 10 MB.

## Data

LATAM Bank data is synthetic and belongs to Factored. **No dataset record is versioned in this repository**: data preparation runs outside the repository, the demo uses a pseudonymized subset that lives only on the server, and the tests use data generated by the team.
